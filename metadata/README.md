# Repository metadata

The metadata files of this repository sit where the tools that read them look for them. This page lists them so that a person or an agent can find each one.

| File | Format | Read by |
|---|---|---|
| [`CITATION.cff`](../CITATION.cff) | Citation File Format 1.2.0 | GitHub's "Cite this repository" and reference managers |
| [`codemeta.json`](../codemeta.json) | CodeMeta 2.0 (JSON-LD) | Software metadata harvesters |
| [`llms.txt`](../llms.txt) | llms.txt convention, generated by `tools/generate_catalog.py` | Language models and agents looking for an index of the Markdown pages |
| [`AGENTS.md`](../AGENTS.md) | Markdown | AI coding agents working in this repository |
| [`catalog/architectures.yaml`](../catalog/architectures.yaml) | YAML, validated by [`schemas/architecture-catalog.schema.json`](../schemas/architecture-catalog.schema.json) | The catalog generator, validators and agents |
| [`testdata/synthetic-speech/croissant.json`](../testdata/synthetic-speech/croissant.json) | Croissant (JSON-LD) | Dataset tools that read Croissant descriptions of the synthetic fixtures |

Keep the version and date in `CITATION.cff` and `codemeta.json` equal when releasing a new version.
